# Frontend logo sources

The compatibility panel uses project-owned artwork from the supported frontends:

- `muos.png`: <https://muos.dev/assets/logo/64.png>
- `nextui.png`: <https://github.com/Loveretro/NextUI/blob/main/github/logo_outline.png>
- `onionos.svg`: <https://github.com/OnionUI/Onion/blob/main/website/static/img/onion_logo.svg>
- `knulli.png`: <https://github.com/knulli-cfw/knulli.org/blob/main/docs/_inc/images/logo-knulli.png>
- `spruce.png`: cropped from <https://github.com/spruceUI/spruceOS/blob/main/App/BootLogo/Imgs/spruce.png>
- `treefrogui.png`: derived from the TreeFrogUI project logo.

The images are used only to identify compatible frontends. Their respective projects retain ownership of their names and marks.
